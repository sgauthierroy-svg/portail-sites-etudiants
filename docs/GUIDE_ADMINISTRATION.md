# Guide d'administration du portail

Mode opératoire de l'administrateur. Document complété au fil du développement.

## Chaque rentrée

### Créer les classes de la nouvelle promotion

À chaque rentrée, une nouvelle promotion de 1re année arrive. Avant d'importer les nouveaux étudiants, créer dans le portail les deux classes de la nouvelle session, par exemple pour la rentrée 2027 :

- « NDRC FI – session 2029 »
- « NDRC ALT – session 2029 »

Cela prend une minute. La 1re ou la 2e année se calcule toute seule à partir de la session : rien d'autre à mettre à jour.

### Archiver les classes terminées

Les classes dont les étudiants sont partis (sous-domaines supprimés) sont archivées. Une classe qui contient encore des étudiants ne peut pas être supprimée.
